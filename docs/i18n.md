# Languages

+ The site speaks 18 languages: English, Spanish, Portuguese, French, German, Italian, Dutch,
  Swedish, Polish, Russian, Turkish, Arabic (right to left), Hindi, Indonesian, Vietnamese, Chinese,
  Japanese and Korean. The list, with flags and names, is `src/core/locales.ts`.
+ **Which language.** A visitor's saved choice (the `locale` cookie, set by the flag menu at the top
  right of the nav) wins; otherwise the first supported language of the browser's `Accept-Language`
  header; otherwise English. `<html lang dir>` follows it.
+ **What is translated.** The interface: nav, theme and language buttons, the About page. The
  dictionaries are `src/shared/i18n/presentation/messages/<code>.ts`; they are typed against the
  English one, so a missing key fails `pnpm typecheck`.
+ **What is not (yet).** Content that lives in the database or in `page-text.ts` (player and game
  texts, page headings, the induction copy, form labels, the admin) stays in English.
+ **Adding a language.** Add it to `LOCALES`, add a `messages/<code>.ts`, register it in
  `messages/index.ts`.
+ **Using it.** A server component calls `getMessages()` (`server-locale.ts`); a client component
  calls `useLocale()` (the shell provides it). Both opt the page into dynamic rendering, which the
  database-backed pages already are.

## About page

+ `/about` describes the project and lists its contributors with their pictures
  (`about-screen.tsx`: a GitHub avatar for the maintainer, a local image under
  `public/images/contributors/` otherwise). Add a person to the `CONTRIBUTORS` list there.

## Notes

+ Reading the language (cookie and header) makes every page dynamic. The pages already are, since
  their data lives in the database.
+ Page titles and descriptions for link previews, and the validation messages, stay English.
